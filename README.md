# Opportunity Radar Africa — website prototype

## Preview
Open `index.html` in a web browser.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `opportunity-radar-africa`.
2. Upload `index.html` to the repository root and commit the change.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. GitHub will provide a public address similar to `https://YOUR-USERNAME.github.io/opportunity-radar-africa/`.

## Important
The six cards are demonstration examples, NOT real opportunities. Replace them with current, researched listings and official application links before public launch. Never label a listing verified until its eligibility, deadline, funding details and official source have been checked.

## Current prototype features
- Responsive mobile and desktop design
- Search by keyword
- Category filters
- Country, funding and level filters
- Demonstration opportunity cards
